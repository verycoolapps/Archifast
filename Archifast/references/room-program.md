# Room Program Benchmarks

Benchmark area ranges (m²) by room type. **Starting points only** — adjust to occupancy, culture, and site constraints. ID = typical Indonesian residential expectation.

## Residential — public

| Room | Area (m²) | Notes |
|---|---|---|
| Entrance/foyer | 2–4 | airlock to living; entry-porch/prayer-room adjacency common in ID homes |
| Living room | 16–28 | 4-seat min; ID homes often target 4×6 m |
| Dining room | 8–14 | 4–6 seats; merges with living in small homes |
| Family room | 14–24 | informal gathering; distinct from formal living in ID homes |
| Prayer room (musholla) | 2–5 | common in ID homes; note orientation toward qibla |
| Guest room | 10–14 | convertible to study |

## Circulation factors

- Corridors/halls: add 8–15% of net area (distribute or centralize deliberately).
- Stairs: ~4–6 m² footprint per floor + landing.
- Structural walls/circulation allowance: +10–15% gross vs. net sum.

## Non-residential quick refs

| Type | Rule of thumb |
|---|---|
| Office (open) | 8–12 m²/person incl. circulation |
| Office (cellular) | 10–15 m²/person |
| Hotel room | 20–32 m² (incl. bath) |
| Retail | 60–70% sellable GFA |
| Classroom | 1.8–2.5 m²/student |
| Hospital ward | 8–12 m²/bed + support |

## Program assembly checklist

1. List every required room from the brief.
2. Assign benchmark area; flag rooms < minimum viable size.
3. Sum net areas → add circulation factor → compare to site capacity (lot × allowed coverage/FAR). If over: propose cuts or vertical expansion BEFORE drawing.
4. Record each room's adjacency requirements — feed Phase 5.
