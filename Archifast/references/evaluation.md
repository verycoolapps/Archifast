# Evaluation Rubric & QC Checklist

## Weighted scoring (per scheme)

Score 1–5 per criterion (1 = fails, 3 = acceptable, 5 = excellent). Multiply by weight, sum → total /5.

| Criterion | Weight | 5 = excellent looks like |
|---|---|---|
| Functional adjacency | 20% | Every ADJ pair satisfied; no circulation crosses private zones |
| Circulation efficiency | 15% | Short paths, no corridor > needed, single-loaded rooms |
| Natural light & ventilation | 15% | Cross-ventilation verified all rooms; daylight factor adequate |
| Privacy zoning | 10% | Public/private/service cleanly sequenced; bedrooms buffered |
| Flexibility / future use | 10% | Rooms convertible; structure allows expansion/upfit |
| Buildability / cost | 10% | Simple orthogonal geometry, standard spans, minimal structure |
| Accessibility | 10% | Step-free key routes, ≥0.8 m doors, turning space in WC |
| Aesthetic / experience | 10% | Coherent spatial idea; views/light sequence intentional |

Presentation: comparison table (criterion × scheme), weighted totals, one-paragraph rationale per scheme, single recommendation with justification.

## QC checklist — run before every delivery

### Geometry & consistency
- [ ] Every room reachable via door or documented open plan
- [ ] No door swings into another door or fixture
- [ ] All dimensions consistent across plan/sections/schedule
- [ ] Room areas sum to gross within stated tolerance; reconciliation shown
- [ ] Walls enclose space; no floating or duplicate walls
- [ ] Stairs: riser ≤175 mm, tread ≥250 mm, width ≥900 mm, headroom ≥2.0 m

### Program & adjacency
- [ ] Room schedule is complete and matches plan exactly
- [ ] All ADJ requirements satisfied or logged as trade-offs
- [ ] Wet rooms clustered; plumbing walls shared where possible
- [ ] Circulation factor accounted for in gross area

### Climate & comfort
- [ ] Orientation minimizes west/east glazing on living/sleeping
- [ ] Cross-ventilation path exists or risk flagged per room
- [ ] Shading (overhang/fins) noted for equator-facing glazing
- [ ] Daylight adequate (room depth vs. window height checked)

### Accessibility
- [ ] Step-free or ramped route entry→key rooms, or limitation stated
- [ ] Accessible door widths ≥0.8 m on routes
- [ ] WC turning space ~1.5×1.5 m or flagged
- [ ] Ramp slope ≤1:12 if proposed

### Documentation & honesty
- [ ] Title block, project name, date, scale bar, north arrow on every sheet
- [ ] Line-weight hierarchy followed; figure-ground diagram present
- [ ] Unverified geometry labeled CONCEPTUAL
- [ ] No invented dimensions, areas, or regulations
- [ ] Regulatory status stated honestly (conceptual; verify with licensed architect)
- [ ] Assumptions block + limitations log included
- [ ] Export files generated per manifest (PNG/SVG/PDF/DXF/IFC/JSON/CSV)
- [ ] CAD layers follow `A-*`/`S-*`/`M-*` naming convention
