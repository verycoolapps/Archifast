# Technical Documentation Package — 12 Steps

Deliver as a single structured document (or sheet set). Each step produces a section; keep language terse and technical.

## 1. Cover sheet
- Project name, site address (or "site TBD"), client, date.
- Drawing index, revision table (R0 = initial AI-assisted concept).
- Status block: `CONCEPTUAL DESIGN — NOT FOR CONSTRUCTION`
- Attribution line: "Prepared with AI assistance; requires verification and stamping by a licensed architect."

## 2. Site analysis summary
- Lot dimensions, orientation, setbacks (or TBD), topography, access, existing structures.
- Solar orientation diagram (north arrow + sun path note for hemisphere/latitude).
- Context notes: adjacent buildings, street hierarchy, views.

## 3. Design brief / program
- Occupancy summary, project goals, constraints (budget band, coverage/FAR if known).
- Room-by-room requirement list from discovery phase.
- Design principles (3–5 bullets) guiding scheme selection.

## 4. Room schedule
Table columns: Room | Local-language name (if applicable) | Area m² | L×W m | Ceiling ht | Occupancy | Adjacency req | Furniture/fixtures | Wet? | Notes.
Sorted by zone (public → private → service → circulation).
Sum line: net area, circulation allowance, gross area, coverage vs. lot.

## 5. Zoning diagram
- Bubble/zoning plan with color-coded zones (public/private/service/circulation).
- Written rationale: why this arrangement (noise, privacy, climate, plumbing).

## 6. Adjacency matrix + diagram
- Matrix table (see `adjacency.md`) with satisfied/trade-off status.
- Bubble diagram showing cluster logic.

## 7. Floor plans
- One sheet per level, dimensioned, with doors/windows/stairs/furniture.
- Level marker, scale, north arrow per sheet.
- Unfurnished + furnished variant where requested.

## 8. Sections / elevations
- Minimum 1 transverse section through key spaces (living + stair + wet stack).
- North + south elevations schematic (massing, openings, roof suggestion).
- Vertical dimensioning: floor-to-floor heights, stair geometry.

## 9. Climate-response notes
- Orientation strategy, cross-ventilation arrows/paths, shading devices.
- Material/roof recommendations for climate zone (tropical defaults noted).
- Daylight strategy per room.

## 10. Accessibility notes
- Step-free route description or limitation.
- Door widths, corridor widths, WC turning space status.
- Explicit statement: "requires verification against applicable accessibility regulations (e.g., SNI in Indonesia)."

## 11. Evaluation matrix + recommendation
- Weighted scores per scheme (see `evaluation.md`).
- Comparison table, rationale paragraphs, final recommendation.

## 12. Export manifest + assumptions log
- File list: every exported artifact with format and purpose.
- Assumptions: every TBD, every inferred value, every unverified check.
- Limitations: what was NOT verified (structure, code, MEP, site survey).
- Iteration log: all user-requested changes and their resolutions.

## Format requirements

- PDF: vector, layers preserved, print-ready (A3/ANSI D sheets or continuous scroll for concept).
- All sheets share title block template.
- Language: English primary; Indonesian room names as subtitles for ID projects.
